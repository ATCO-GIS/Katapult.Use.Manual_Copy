# Katapult Use Manual

Welcome! This site contains detailed instructions for using Katapult Pro. Use it alongside the Katapult SOP Word document located in OneDrive [input file path when final version is created].

## How to Navigate

The sidebar contains links to each section. Click on any topic to jump to that section.

## Manual Summary

- **Photos Overview and Classification** – How to classify photos, calibrate measurements, and enter photo data
- **Annotations, Tracing, & Hardware Details** – How to mark up poles, trace cables, and enter attachment information
- **Katapult OSP Training** – Reference material on pole anatomy, power lines, communication cables, and underground facilities
- **Office Power Tools** – Instructions for bulk editing, multi-delete, polygon tools, and other advanced office functions

## Finding What You Need

1. Look for your topic in the sidebar menu
2. Click to expand subsections
3. Use your browser's search (Ctrl+F or Cmd+F) or use the integrated search bar in the top right.
